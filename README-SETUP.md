# ELECTRI4KA · SMM Studio — повне налаштування з нуля

Усе безкоштовне. Знадобиться ~40 хвилин один раз. Роби кроки по порядку, нічого не пропускай.

**Що отримаєш у результаті:**
- Сайт-додаток за посиланням (працює з телефона), вхід через Telegram для вас трьох
- Спільна база: дошка завдань, сценарії, календар, статистика — синхронізуються між усіма
- Вкладка «ШІ»: щодня о 12:00 з'являються 5–7 креативів; лайки від усіх = ШІ надсилає фінальний файл у Telegram; нотатка = завтра приходить виправлена версія
- Бот у вашій групі: щоденне нагадування про сценарії + креативи у повній якості

**Структура файлів (так і має виглядати репозиторій):**

```
smm-studio/
├── index.html                          ← сам додаток
├── README-SETUP.md                     ← ця інструкція
├── creatives/
│   ├── index.json                      ← список креативів (веде ШІ)
│   └── sample-creative.png             ← приклад
├── data/
│   ├── outbox.json                     ← черга повідомлень для бота (веде ШІ)
│   └── state.json                      ← з'явиться сам після першого експорту бази
├── scripts/
│   └── export-db.js                    ← скрипт експорту бази
└── .github/
    └── workflows/
        ├── send-telegram.yml           ← бот-розсилка
        └── export-db.yml               ← експорт бази для ШІ
```

## КРОК 1. Створи бота в Telegram (5 хв)

1. Відкрий Telegram, знайди **@BotFather** (з галочкою), натисни **Start**
2. Надішли команду: `/newbot`
3. На питання про назву напиши: `ELECTRI4KA SMM`
4. На питання про юзернейм напиши щось на кшталт: `electri4ka_smm_bot` (має закінчуватись на `bot`; якщо зайнято — додай цифру)
5. BotFather відповість повідомленням з **токеном** — рядок типу `8123456789:AAEhBOweik6ad9r_QXMENQTKNCaCTX0000A`
6. **Скопіюй токен і збережи** — він знадобиться в кроках 5 і 7. Нікому його не показуй, крім GitHub Secrets і Клода

## КРОК 2. Створи групу і дізнайся її ID (5 хв)

1. У Telegram: меню → **Створити групу**, назва — наприклад «ELECTRI4KA контент»
2. Додай двох колег
3. Додай бота: у групі → назва групи вгорі → **Додати учасника** → знайди свого бота за юзернеймом → додай
4. Напиши в групу будь-яке повідомлення, яке згадує бота, наприклад: `@electri4ka_smm_bot привіт`
5. Відкрий у браузері адресу (підстав СВІЙ токен замість `<ТОКЕН>`):
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
6. На сторінці з'явиться текст. Знайди в ньому шматок `"chat":{"id":-100xxxxxxxxxx` — оце число **з мінусом** і є **CHAT_ID** групи. Збережи його
   - Якщо сторінка показує `"result":[]` — напиши в групу ще одне повідомлення зі згадкою бота і онови сторінку

## КРОК 3. Створи базу даних Firebase (10 хв)

1. Іди на **console.firebase.google.com**, увійди з Google-акаунтом
2. Натисни **Create a project** (Створити проєкт)
   - Назва: `electri4ka-smm`
   - Google Analytics: **вимкни** (не потрібен) → Create project → Continue
3. Увімкни базу: в лівому меню **Build → Firestore Database** → **Create database**
   - Location: `eur3 (Europe)` → Next
   - Режим: **Start in production mode** → Create
4. Постав правила доступу: вкладка **Rules** (Правила) → зітри все і встав:
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /app/{doc} {
         allow read, write: if request.auth != null;
       }
     }
   }
   ```
   → натисни **Publish**
5. Увімкни вхід: **Build → Authentication** → **Get started** → вкладка **Sign-in method** → **Anonymous** → увімкни перемикач → Save
6. Зареєструй додаток: шестерня вгорі зліва → **Project settings** → прокрути до **Your apps** → натисни іконку **</>** (Web)
   - Nickname: `smm-studio` → **Register app**
   - З'явиться код з `const firebaseConfig = { apiKey: "...", ... }` — **скопіюй усі значення** (apiKey, authDomain, projectId, storageBucket, messagingSenderId, appId). Вони підуть у крок 6
7. Ключ для ШІ: там же в **Project settings** → вкладка **Service accounts** → кнопка **Generate new private key** → **Generate key** — завантажиться файл `.json`. Збережи його, він піде в крок 5

## КРОК 4. Створи репозиторій на GitHub і завантаж файли (10 хв)

1. Зареєструйся/увійди на **github.com**
2. Вгорі справа **+** → **New repository**
   - Repository name: `smm-studio`
   - Тип: **Public** (для безкоштовного хостингу)
   - Постав галочку **Add a README file**
   - → **Create repository**
3. Завантаж файли з архіву, який дав Клод (`smm-studio.zip`, розпакуй його спочатку):
   - У репозиторії натисни **Add file → Upload files**
   - Перетягни туди: `index.html`, `README-SETUP.md`, папки `creatives`, `data`, `scripts` (тягни цілими папками з провідника — структура збережеться)
   - Внизу натисни **Commit changes**
4. Папку `.github` завантажити перетягуванням не вийде (вона прихована), тому створи два файли вручну:
   - **Add file → Create new file** → у полі імені набери точно: `.github/workflows/send-telegram.yml` (слеші створять папки) → встав вміст файлу `send-telegram.yml` з архіву → **Commit changes**
   - Ще раз **Add file → Create new file** → ім'я: `.github/workflows/export-db.yml` → встав вміст `export-db.yml` → **Commit changes**

## КРОК 5. Додай секрети (ключі) в репозиторій (5 хв)

У репозиторії: **Settings** (вкладка вгорі) → зліва **Secrets and variables → Actions** → кнопка **New repository secret**. Створи три секрети по черзі:

| Name (точно так) | Secret (значення) |
|---|---|
| `BOT_TOKEN` | токен бота з кроку 1 |
| `CHAT_ID` | ID групи з кроку 2 (з мінусом, напр. `-1001234567890`) |
| `FIREBASE_SERVICE_ACCOUNT` | відкрий завантажений у кроці 3.7 `.json` файл блокнотом, скопіюй УВЕСЬ вміст і встав |

## КРОК 6. Впиши налаштування в index.html (5 хв)

1. У репозиторії відкрий файл `index.html` → натисни **олівець** (Edit this file) угорі справа
2. Знайди на початку блок `НАЛАШТУВАННЯ` (рядки з `ВСТАВ_СЮДИ`) і заміни:
   - у `FIREBASE_CONFIG` — значення з кроку 3.6 (apiKey, authDomain, projectId, storageBucket, messagingSenderId, appId)
   - `TG_BOT_USERNAME` — юзернейм бота **без @**, напр. `electri4ka_smm_bot`
   - `ALLOWED_TG_IDS` — Telegram ID вас трьох, напр. `[123456789, 987654321, 555555555]`
     - Свій ID кожен дізнається за 10 секунд: напишіть боту **@userinfobot** будь-що — він відповість вашим Id
   - `ADMIN_TG_IDS` — ID адміна (або адмінів), напр. `[123456789]` — тільки вони бачать кнопку «⚡ Виправити зараз» у вкладці ШІ. Лишиш порожнім — кнопку бачитимуть усі троє
3. Внизу **Commit changes**

## КРОК 7. Увімкни хостинг (3 хв)

1. У репозиторії: **Settings → Pages** (зліва)
2. Source: **Deploy from a branch**; Branch: **main**, папка **/ (root)** → **Save**
3. Почекай 1–2 хвилини, онови сторінку — з'явиться посилання типу:
   `https://ТВІЙ_ЛОГІН.github.io/smm-studio/`
   Це і є адреса додатка — збережи і скинь колегам
4. Прив'яжи домен до бота, щоб працювала кнопка входу: у **@BotFather** надішли `/setdomain` → вибери свого бота → надішли: `ТВІЙ_ЛОГІН.github.io`

## КРОК 8. Перевір, що все живе (5 хв)

1. Відкрий `https://ТВІЙ_ЛОГІН.github.io/smm-studio/` на телефоні → має з'явитися кнопка **«Log in with Telegram»** → увійди → побачиш порожню дошку. Так само заходять колеги
2. Створи тестове завдання — воно має з'явитись у колег (онови сторінку в них)
3. Перевір бота: у репозиторії вкладка **Actions** → зліва **telegram-send** → кнопка **Run workflow** → Run. За хвилину статус стане зеленим (перший запуск нічого не надішле — черга порожня, це нормально)
4. Перевір експорт бази: **Actions → export-db → Run workflow**. Коли позеленіє — у папці `data` з'явиться `state.json`

## КРОК 9. Підключи ШІ (Клода) — фінал

Надішли Клоду в чат три речі:

1. **Токен бота** (з кроку 1)
2. **CHAT_ID групи** (з кроку 2)
3. **GitHub-токен доступу до репозиторію**, щоб ШІ міг класти креативи і повідомлення:
   - GitHub → клікни свою аватарку вгорі справа → **Settings** → зліва в самому низу **Developer settings** → **Personal access tokens → Fine-grained tokens** → **Generate new token**
   - Token name: `claude-smm`; Expiration: **90 days** (потім оновиш)
   - Repository access: **Only select repositories** → вибери `smm-studio`
   - Permissions → Repository permissions → **Contents: Read and write** та **Actions: Read and write**
   - → **Generate token** → скопіюй рядок, що починається з `github_pat_...`

Після цього Клод створить дві постійні задачі:

**Щодня о 12:00:**
- у вкладці «ШІ» з'являються 5–7 нових креативів на погодження
- бот пише в групу нагадування: які сценарії у роботі, що заплановано на сьогодні в календарі, скільки креативів чекає на лайки
- затверджені креативи (усі лайкнули) летять у групу файлом у повній якості

**Щогодини (перевірка правок):**
- якщо адмін натиснув «⚡ Виправити зараз» — Клод бачить запит і нотатки, перегенеровує креатив і оновлює його у вкладці ШІ протягом години, а бот пише в групу «виправлена версія готова»

**Якщо щось не працює:**
- Кнопка Telegram-входу не з'являється → перевір крок 7.4 (`/setdomain`) і що `TG_BOT_USERNAME` без @
- «Не вдалося підключитися до бази» → перевір крок 3.5 (Anonymous увімкнено) і конфіг у кроці 6
- Бот мовчить → перевір секрети (крок 5): назви точно `BOT_TOKEN` і `CHAT_ID`, CHAT_ID з мінусом
- Actions червоні → відкрий запуск, скрін помилки — Клоду, він розбереться
